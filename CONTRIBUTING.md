# Contributing to Antigravity for Android

Thanks for helping improve Antigravity for Android!

## Reporting Bugs & Suggesting Features
- **Bugs:** Open an [Issue](../../issues) and include your device model, Android version, and steps to reproduce.
- **Ideas & Questions:** Post in [Discussions](../../discussions).

## Submitting Code (Pull Requests)
1. Fork the repository and create a new branch (`git checkout -b fix/your-feature`).
2. Make sure the debug APK compiles cleanly (`./gradlew :app:assembleDebug`).
3. Open a Pull Request describing what you changed and why.
