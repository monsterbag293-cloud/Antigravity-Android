# Phase P3.6: Architecture Comparison Matrix

## 1. Executive Summary

This document provides a rigorous, side-by-side architectural comparison of all investigated options for running or connecting to the Antigravity backend.

Each architecture is evaluated against the 10 mandatory requirements defined in the project brief. Architectures are ranked by how closely they achieve the **genuine Antigravity experience** while minimizing external infrastructure and user friction.

## 3. Detailed Architectural Ranking

### Rank 1: Mode A — Paired Desktop Hub (Current Implementation)
- **Score**: **9.0 / 10**
- **Why**: Mode A is the **only architecture that currently achieves 100% genuine Antigravity functionality** without requiring a paid subscription, without violating Google Terms of Service, and without encountering fatal Android OS compatibility barriers.
- **Trade-off**: Requires the user's desktop computer to remain powered on and running `language_server.exe`.

---

### Rank 2: Mode B3 — Self-Hosted Remote Hub (`antigravity-server` on VPS)
- **Score**: **7.5 / 10**
- **Why**: For users seeking true mobility away from home without leaving their desktop on, running `antigravity-server` on a headless Linux VPS (e.g. Oracle Cloud Free Tier or a $5/mo cloud VM) provides 100% genuine Antigravity agent functionality.
- **Trade-off**: Requires external server management and Linux sysadmin configuration, failing the "No separately operated server" requirement for standard consumer users.

---

### Rank 3: Mode B2 — Official Google Remote Agents (`antigravity.google.com`)
- **Score**: **6.0 / 10**
- **Why**: Cloud-hosted directly by Google with zero user server maintenance.
- **Trade-off**: Fails two critical mandatory requirements: it mandates a **paid Google AI Pro ($19.99/mo) or Ultra ($99.99/mo)** subscription, and its underlying protocol is private and unsupported for third-party clients.

---

### Rank 4: Mode B5 — Local Gemini Fallback (Pure Kotlin Engine)
- **Score**: **5.0 / 10**
- **Why**: Operates 100% standalone inside the APK without any desktop or server. Completely free using Google AI Studio API keys.
- **Trade-off**: It is **not the genuine Antigravity agent**. It lacks original Cloud Code models (`Gemini 4 Argon`, `Claude Sonnet 5.5`), does not connect to Google Pro account entitlements, and replaces Google's complex Cortex engine with a custom Kotlin loop. It serves strictly as a basic fallback.

---

### Rank 5: Mode B4 — Google Cloud Shell Ephemeral Host
- **Score**: **3.5 / 10**
- **Why**: Zero subscription cost and runs on Google-provided infrastructure.
- **Trade-off**: Prohibitive 20-minute inactivity shutdown makes it unusable as a reliable mobile companion without constant manual interaction.

---

### Rank 6: Mode B1 — Embedded `language_server` in APK
- **Score**: **0.0 / 10 (Technically & Legally Blocked)**
- **Why**: Fatal incompatibilities across every layer of the Android OS stack: dynamic linker (glibc vs Bionic), SELinux W^X execution denial, kernel 39-bit VA crash with TCMalloc, and complete absence of a developer userland (git, node, compilers). In addition, redistributing Google's proprietary 187 MB binary violates Google's copyright.
