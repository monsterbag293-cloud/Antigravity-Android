# Phase P3.6: Free Options & Subscription Analysis

## 1. Executive Summary

This document evaluates all genuinely free ($0/month) options available within the Google and cloud ecosystem to determine whether any route can satisfy the mandatory project requirements:
- **No paid hosting**
- **No forced paid subscription**
- **No desktop computer required**
- **Genuine original Antigravity agent**

Our investigation concludes that **no genuinely free route currently enables headless, standalone Antigravity execution without an active desktop machine or a separately operated external server.**

### 2.1 Google Antigravity Official Free Individual Tier ($0/month)

Google provides a free tier for Antigravity, but its scope is strictly bounded:

#### What Is Included for Free:
- Core Gemini models (Gemini Flash baseline).
- Unlimited inline tab code completions.
- Standard IDE features and Cascade chat within the desktop application.
- Weekly rate limits on deep reasoning queries.

#### What Is Excluded:
- **Remote Agents is completely disabled**:
  Google's official documentation explicitly reserves cloud-hosted **Remote Agents** for **Google AI Pro ($19.99/month)** and **Google AI Ultra ($99.99/month)** subscribers.
- Advanced Cloud Code model allocations (e.g., unlimited `Gemini 4 Argon High`).
- Cloud workspace virtual machines.

**Impact on Mode B**: A user on Google's free tier **cannot** use Google's official cloud backend to run Antigravity headlessly. Mode B via Google's cloud is impossible without a paid subscription.

---

### 2.2 Google AI Studio Free Tier (`generativelanguage.googleapis.com`)

Google AI Studio provides a free API tier for developers using their personal Google accounts:

#### Quotas & Limitations:
- **Rate Limits**: 15 requests per minute (RPM), 1,000,000 tokens per minute (TPM), and 1,500 requests per day (RPD) on models like `gemini-2.5-flash`.
- **Cost**: Completely free ($0/month) without entering a credit card.
- **Data Privacy**: Free-tier prompts may be used for model training under Google's consumer terms.

#### Why It Fails the Mode B Objective:
- It is a raw **LLM inference API**, not an autonomous coding agent.
- It does not provide the genuine Antigravity Cascade cortex reasoning loop, multi-step planning, or safety monitors (`sir_flash_lite`, `agy_tool_safety`).
- It does not provide Cloud Code models (`Gemini 4 Argon High/Med`, `Claude Sonnet 5.5`).
- Using it requires the custom Kotlin `AgentRuntime` (P1.2/P1.3 fallback), which the project mandate explicitly identifies as an isolated compatibility fallback, **not** genuine Antigravity.

### 2.3 Free Cloud Infrastructure Options

We investigated whether a user could legitimately run a headless backend (such as `AFSlayer/antigravity-server`) on free third-party cloud infrastructure.

#### 2.3.1 Oracle Cloud "Always Free" Tier
- **Specs**: Up to 4 ARM Ampere A1 OCPUs, 24 GB RAM, 200 GB block storage.
- **Antigravity Compatibility**: Sufficient memory and CPU to run `language_server` on Linux ARM64 with 48-bit address space.
- **Hurdles & Failure Points**:
  1. **Credit Card Required**: Oracle requires a valid credit card during signup for identity verification, even for the free tier.
  2. **Severe Capacity Shortages**: Always Free ARM instances are frequently "out of capacity" across major global regions for months at a time.
  3. **High Sysadmin Friction**: Requires manually configuring Linux security lists, iptables, SSH keys, systemd service units, Caddy reverse proxies, and dynamic DNS.
  4. **Violates Requirement**: Fails the mandatory requirement: *"No separately operated server"*.

#### 2.3.2 Google Cloud Shell (Free 50 Hours/Week)
- **Specs**: Free Debian Linux VM with 5 GB persistent home directory, pre-installed with `git`, `python`, `node`, `go`, and `docker`.
- **Antigravity Compatibility**: Capable of executing `language_server` or the `antigravity-server` Go wrapper.
- **Hurdles & Failure Points**:
  1. **20-Minute Inactivity Shutdown**: Cloud Shell strictly terminates the container if no interactive web terminal keystrokes are received for 20 minutes.
  2. **Weekly Quota Limits**: Capped at 50 hours per week.
  3. **Ephemerality**: Non-home filesystem state is reset across sessions.
  4. **High User Friction**: The user must open a browser, log in to `shell.cloud.google.com`, restart the server script, and refresh web preview URLs manually.

#### 2.3.3 GitHub Codespaces (Free 60 Core-Hours/Month)
- **Specs**: 2-core Linux VM with 32 GB storage.
- **Hurdles & Failure Points**:
  1. **Auto-Sleep**: Automatically suspends after 30 minutes of idle time.
  2. **Limited Monthly Hours**: 60 core-hours equals only 30 hours of 2-core runtime per month (1 hour per day).
  3. **Requires Separate Account & Setup**: Requires an active GitHub account and manual container orchestration.

#### 2.3.4 Free PaaS Tiers (Render, Fly.io, Railway)
- **Memory Caps**: Free tiers typically provide 256 MB – 512 MB of RAM.
- **Failure**: The `language_server` binary alone occupies 187 MB on disk and requires at least 1 GB of resident RAM when executing. Free PaaS instances are immediately killed by Out-Of-Memory (OOM) managers.

## 4. Conclusion on Free Options

There is **no viable zero-cost, zero-server route** that provides the genuine Antigravity agent without a desktop computer:
1. Google's official free tier deliberately gates cloud-hosted Remote Agents behind a **$19.99/month paid subscription**.
2. Free cloud hosting alternatives (Oracle Free, Cloud Shell) violate the core requirement of avoiding separately operated servers and suffer from auto-shutdowns, capacity limits, and prohibitive user friction.
3. Completely free public AI Studio keys replace the authentic agent with a generic LLM.
