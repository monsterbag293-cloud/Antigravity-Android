### Model Identification & Compatibility
- **Proposed & Adopted Model ID:** `gemini-3.5-flash-lite`
- **Google Generative Language API Status:** Active production model. High-throughput, low-latency multimodal architecture optimized for sub-agents, tool execution, and code analysis.
- **Function Calling Support:** Fully supported via `tools.functionDeclarations` with `toolConfig.functionCallingConfig.mode: "AUTO"`.
- **Reasoning / Thinking Support:** Supports `thinkingConfig` under `generationConfig`. Default thinking level is `MINIMAL`, but setting `thinkingLevel: "LOW"` provides the planning reasoning required for complex multi-step tool sequences while preserving fast response times.

### Dynamic Model Resolution
Models are not hardcoded. Configured via `GeminiModelProvider.defaultModelId()` and `normalizeGeminiModelId`:
1. Environment variable: `GEMINI_DEFAULT_MODEL` (e.g., `gemini-3.8-flash` or `gemini-3.5-flash-lite`).
2. System property: `-DGEMINI_DEFAULT_MODEL=...`.
3. Direct request parameter: `ModelRequest(modelId = ...)`.
4. Legacy alias mapping:
   - `MODEL_PLACEHOLDER_M18` → `gemini-3.5-flash-lite` (Antigravity Recommended)
   - `MODEL_PLACEHOLDER_M19` → `gemini-3.8-pro`
   - `gemini-2.5-flash` → `gemini-3.8-flash` (auto-remap to avoid 404)
   - `gemini-2.5-flash-lite` → `gemini-3.5-flash-lite`

   ```kotlin
       }
   }
   ```
3. **Local Machine Key Discovery:** `realKey()` inspects `System.getenv("GEMINI_API_KEY")`, `System.getenv("GOOGLE_API_KEY")`, `local.properties` (`gemini.api.key`), and `~/.gradle/gradle.properties`.
