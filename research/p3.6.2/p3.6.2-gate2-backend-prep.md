## 3. Cryptographic Authenticity vs Transport Checksums

### 3.1 GCS Transport Checksums (Not Cryptographic Proof)
Google Cloud Storage returns the following transport headers for this artifact:
- `x-goog-hash: crc32c=gCBY0w==`
- `ETag: "-CNvl3K/d9JcDEAE="`

**Technical Distinction**:
- **CRC32C** is an error-detecting cyclic redundancy code (32-bit polynomial). It detects bit flips during network transit, but is **not** a cryptographic collision-resistant hash. It provides zero security against malicious tampering.
- **ETag** on GCS composite objects represents an internal generation composite string, not a verifiable cryptographic signature.
- Google does **not** publish external detached GPG/PGP signatures or `.sha256` files in the public bucket (requests to `.sig`, `.sha256`, `manifest.json`, and `SHA256SUMS` return HTTP 404).

### 3.2 First-Party Desktop Verification Architecture
Audit of Google's official desktop application (`app.asar/out/main/index.js`) reveals how Google itself verifies and installs this Linux binary when running under WSL:
```javascript
async function installServerBinary(distro, version, data) {
    const sha256 = crypto.hash('sha256', data, 'hex');
    const script = buildInstallScript(version, sha256);
    // ...
}

function buildInstallScript(version, sha256) {
    const dir = serverInstallDir(version);
    return [
        'set -e',
        `dir="${dir}"`,
        'mkdir -p "$dir"',
        'tmp="$dir/.language_server.partial.$$"',
        'trap \'rm -f "$tmp"\' EXIT',
        'cat > "$tmp"',
        `echo "${sha256}  $tmp" | sha256sum -c - >/dev/null`,
        'chmod +x "$tmp"',
        'mv -f "$tmp" "$dir/language_server"',
        'trap - EXIT',
    ].join('; ');
}
```
**Google's Security Model**:
1. Transport layer security relies on **direct HTTPS TLS validation** against Google's authoritative domain (`storage.googleapis.com`).
2. An on-the-fly **SHA-256 hash** is calculated on the received byte stream.
3. The written file is verified using `sha256sum -c` to guarantee atomic write integrity before making the binary executable.
