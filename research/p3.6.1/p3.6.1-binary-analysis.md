## 5. ELF Interpreter (`PT_INTERP`)

Reading the exact bytes at offset `0x0b3d5118` (length 27 bytes):
```
Raw Hex: 2f 6c 69 62 2f 6c 64 2d 6c 69 6e 75 78 2d 61 61 72 63 68 36 34 2e 73 6f 2e 31 00
String:  /lib/ld-linux-aarch64.so.1
```
- **Finding**: The binary is dynamically linked and mandates the GNU AArch64 dynamic linker: `/lib/ld-linux-aarch64.so.1`.
- **Significance for Android**: Android does not have `/lib/ld-linux-aarch64.so.1`. Android's 64-bit linker is located at `/system/bin/linker64`.

## 7. Symbol Version Requirements (`DT_VERNEED`)

Parsing the `Elf64_Verneed` and `Elf64_Vernaux` structures at offset `0x5b94` uncovered the exact GNU libc version requirements:

```
Dependency 0: libresolv.so.2 -> requires GLIBC_2.17
Dependency 1: libpthread.so.0 -> requires GLIBC_2.17
Dependency 2: libm.so.6       -> requires GLIBC_2.17
Dependency 3: libdl.so.2      -> requires GLIBC_2.17
Dependency 4: librt.so.1      -> requires GLIBC_2.17
Dependency 5: libc.so.6       -> requires:
                                   GLIBC_2.17
                                   GLIBC_2.18
                                   GLIBC_2.25
                                   GLIBC_2.26
```

### Critical Version Insight
- The absolute maximum glibc version required is **`GLIBC_2.26`** (released in August 2017).
- This proves Google deliberately compiles `language_server` with backward-compatible toolchains (e.g. Ubuntu 18.04 LTS / Debian 10 Buster compatible).
- Any Linux rootfs with `glibc >= 2.26` (which includes all current Debian 11/12 and Ubuntu 20.04/22.04/24.04 ARM64 rootfs images) fully satisfies every symbol requirement.

## 8. Go Runtime & CGO Implementation Details

Binary pattern analysis revealed:
1. **Go Toolchain**: `go1.28-20261025-RC00` (Google internal Go compiler release).
2. **CGO Integration**: The binary is **not** a pure `CGO_ENABLED=0` static binary. It compiles C++ components statically into the binary while dynamically linking against the system's glibc.
3. **C++ Subsystems Included**:
   - `third_party/tcmalloc` (Thread-Caching Malloc with sampling and arena allocators)
   - `google::protobuf` (Protobuf descriptor registry and reflection)
   - `absl::flags` (Command-line flag parsing)
